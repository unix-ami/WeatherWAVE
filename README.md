# WeatherWAVE
The weather app sailors have been waiting for!

### Setup:

Please run in Chrome. If geolocation stops working, follow these steps to reset permissions:

1. Open the app in Chrome.
2. Click the **lock icon** in the address bar.
3. Go to **Site Settings** for localhost. 
4. Reset all permission and data. 
5. Refresh the page.

Certain web extensions may interfere with the map. Disable extensions like ad blockers if you encounter issues.
